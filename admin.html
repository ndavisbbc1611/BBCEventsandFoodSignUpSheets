First time here? How to get a GitHub token
  1. Go to github.com and log in, then go to Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click "Generate new token." Give it a name like "signup-admin."
  3. Under "Repository access," choose "Only select repositories" and pick this repository.
  4. Under "Permissions," find "Contents" and set it to "Read and write."
  5. Click "Generate token" and copy it immediately — GitHub only shows it once.
  6. Paste it into the "GitHub Token" field below. Keep it private, like a password.
